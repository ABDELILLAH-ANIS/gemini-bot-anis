# 🤖 بوت تيليجرام لبيع اشتراكات Google Gemini Pro (نظام الموزع المتكامل)

بوت احترافي متكامل مبني بلغة **Python** لبيع اشتراكات جيميني برو للعملاء بأسعارك المحددة وتحقيق أرباحك، مع نظام تسليم هجين ثلاثي المراحل يجمع بين:
1. **المخزن المحلي (Local Stock):** روابط مخزنة مسبقاً في قاعدة بيانات البوت.
2. **سحب تلقائي عبر API المورد (LahaStore API):** شراء وسحب فوري للروابط بسعر الجملة عند موافقة الأدمن على الطلب.
3. **التسليم اليدوي (Manual Fallback):** في حال نفاد المخزن المحلي ورصيد الـ API، يطلب البوت من الأدمن كتابة الرابط يدوياً.

---

- **جيميني برو 18 شهر:** `1100` دينار (سعر الجملة لدى المورد: ~$0.80)
- **جيميني برو 12 شهر:** `1000` دينار

*(يمكنك تعديل الأسعار أو إضافة باقات جديدة بسهولة من ملف `config.py`)*

افتح ملف `.env` وقم بملء البيانات التالية:
```env

# إعدادات API المورد (مضبوطة وجاهزة بالفعل)
SUPPLIER_BASE_URL=https://lahastore.up.railway.app/api/v1
SUPPLIER_SHOP_ID=TG5075624178
SUPPLIER_API_KEY=psk_w8FN2yLrZ5XEovOCDLPf2diXbForvGO9X5k79bARmYt9Hs
```

### 2. تشغيل البوت بنقرة واحدة

- سيتولى السكربت تفعيل البيئة وتشغيل البوت فوراً.

1. **🏦 بريدي موب (BaridiMob):** بالدينار الجزائري (حسب سعر الباقة).
2. **💳 RedotPay:** بسعر **`2.5$`** للحبة (عبر UID: `1445653765`).
3. **🟡 Bybit:** بسعر **`2.5$`** USDT للحبة (عبر UID: `593583401`).

---

## 🔄 مسار العميل (الزبون)
1. يضغط العميل `/start`.
2. يختار باقة الاشتراك والكمية (1، 2، 3...).
3. يختار **طريقة الدفع** المناسبة (بريدي موب، RedotPay، أو Bybit).
4. يعرض البوت ملخص الطلب مع المبلغ المحسوب بالعملة المختارة (دينار أو دولار) وبيانات التحويل مع زر نسخ الـ UID.
5. يرسل العميل **صورة إشعار/وصل التحويل** مع **رقم الحوالة أو الـ TxID**.
6. يستلم العميل إشعاراً بنجاح إرسال الطلب وحالته "قيد المراجعة والتحقق".

## 🛡 لوحة تحكم المسؤول (الأدمن)
1. **إشعار الطلبات الجديدة:**
   - يصل إشعار فوري للأدمن يحتوي على صورة الوصل، رقم الحوالة، بيانات العميل، والمبلغ المطلوب.
   - زران تفاعليان: `[✅ قبول وتسليم الرابط]` و `[❌ رفض الطلب]`.
2. **آلية القبول والتسليم الهجين:**
   - عند ضغط "قبول":
     - يفحص المخزن المحلي أولاً.
     - إن لم يتوفر، يسحب الرابط ويشتريه تلقائياً عبر API المورد LahaStore.
     - إن لم يتوفر رصيد، يطلب من الأدمن كتابة الرابط يدوياً ثم يسلمه للعميل فوراً.
3. **أمر `/admin`:**
   - 🏷️ **إدارة المنتجات والأسعار:**
     - ✏️ **تعديل أسعار المنتجات:** اختر أي منتج واكتب سعره الجديد ليتغير فوراً أمام كل الزبائن.
     - ➕ **إضافة منتج جديد:** أضف أي منتج تريده (مثل ChatGPT Plus، Canva Pro، إلخ) بتحديد اسمه وسعره ووصفه.
     - 👁️ **إيقاف / تفعيل منتج:** إخفاء أو إظهار أي منتج في قائمة الشراء بضغطة زر.
   - 📊 **الإحصائيات:** إجمالي الطلبات، المقبولة، المعلقة، الأرباح، وعدد العملاء.
   - 📦 **جرد المخزن:** عدد الروابط المتوفرة محلياً لكل باقة.
   - ➕ **إضافة روابط:** إضافة روابط جديدة للمخزن دفعة واحدة.
   - 🌐 **رصيد ومخزن المورد:** فحص رصيد محفظة الدولار لدى LahaStore ومخزونهم المباشر.
   - 💳 **تعديل بيانات الدفع:** تغيير حساب بريدي موب وطرق الدفع دون تعديل الكود.

## 📁 بنية المشروع
```
gemini_sub_bot/
├── main.py               # نقطة التشغيل الرئيسية وموزع الأوامر
├── config.py             # الأسعار، المنتجات، الإعدادات العامة
├── database.py           # قاعدة بيانات SQLite (الطلبات، المخزن، الإحصائيات)
├── supplier_api.py       # عميل الاتصال بـ API المورد (LahaStore)
├── keyboards.py          # لوحات المفاتيح والأزرار التفاعلية
├── handlers_customer.py  # تدفق طلب الشراء وإرسال الوصل للعميل
├── handlers_admin.py     # لوحة تحكم الأدمن والتحقق من الحوالات
├── requirements.txt      # المكتبات المطلوبة
├── run.bat               # تشغيل بنقرة واحدة على ويندوز
└── .env                  # التوكن ومفاتيح الربط
```
